01 Data mining pipeline Raw data → prediction
→
01 / COLLECT
Data ingestion
Historical records from 12 weather stations — temperature, humidity, wind speed, pressure, dew point. 10-year archive.
→
02 / CLEAN
Preprocessing
Missing value imputation, outlier removal via IQR, duplicate record detection, timezone normalisation.
→
03 / ENGINEER
Feature engineering
Lag features (t-1, t-7), 7-day rolling averages, Fourier seasonal encoding, derived dew point and heat index.
→
04 / SPLIT
Train / val / test
80 / 10 / 10 time-series split with walk-forward cross-validation to prevent data leakage.
05 / MODEL
Train & tune
Grid-search hyperparameter optimisation. Bayesian tuning for LSTM. Ensemble stacking for final output.
